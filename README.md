# 可可遊戲室

以巧克力與可可為主題的互動學習遊戲，使用 Phaser.js 製作，並透過 GitHub Pages 發布。

## 線上遊玩

網站首頁：[可可遊戲室](https://gloriakao.github.io/chocoMathGame1/)

### 可可三角研究所

台灣國中三年級三角形幾何冒險，包含三個關卡，練習畢氏定理、相似三角形與角度概念。

[開始幾何冒險](https://gloriakao.github.io/chocoMathGame1/triangle-game.html)

### 可可工坊

限時辨認黑可可、牛奶可可與草莓可可。點選目標類型才能得分，遊戲開始前會先展示三種可可豆圖示。

[開始可可挑戰](https://gloriakao.github.io/chocoMathGame1/cocoa-clicker.html)

## 遊戲式學習指南

認識遊戲式學習，以及十種適合課堂應用的遊戲機制與 Phaser 互動範例。

[閱讀遊戲式學習指南](https://gloriakao.github.io/chocoMathGame1/learning.html)

## 技術與發布

- Phaser.js 遊戲範例
- Bootstrap 透過 CDN 載入
- GitHub Pages 自動部署 `dist/` 資料夾
- 推送至 `main` 分支會觸發 `.github/workflows/pages.yml`
